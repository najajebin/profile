# Personal academic site

Plain HTML and CSS, no build step. Hosted on GitHub Pages.

## Publish
1. Create a public repo named `YOUR-GITHUB-USERNAME.github.io` and upload everything in this folder.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. The site appears at `https://YOUR-GITHUB-USERNAME.github.io`.

## Before publishing
- Replace `YOUR-GITHUB-USERNAME` and `YOUR-LINKEDIN` in `index.html`.
- Add `cv.pdf` to the root. Use a copy without phone number and CGPA.
- Add photos to `images/` (3:2 crop, under 300 KB each) and uncomment the `<figure>` blocks in `research.html`. Ask each supervisor first.
- Get Prof. Vasu's go-ahead before adding specific JNCASR results; the entry currently says only that early results point to candidate neuron groups.
